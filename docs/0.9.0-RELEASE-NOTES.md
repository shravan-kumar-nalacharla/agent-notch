# Agent Notch 0.9.0

Adds separate Reading, Courses and Workout modules, a shared durable background reminder engine, Notification Center, water scheduling improvements and optional Spotify Connect. Details open only after a click; the compact island, existing media/tasks/timers, five language styles, curated quotes and 0.8.0 settings/Gemini fixes are preserved.

- Books: added/absolute page logs, correction/undo, page-aware searchable notes, progress estimates, reading clocks/history, filters, archive/restore and Markdown/JSON export.
- Courses: manual lessons and sections, explicit completion, skipped/revisit states, notes with manual timestamps, safe browser continuation, CSV/JSON/pasted lesson import and optional public YouTube metadata/playlist import. Study/Career/Personal presets, planned start, expected duration and daily minutes remain explicitly editable and never enable reminders automatically.
- Workouts: reusable custom routines, categories/exercises/sets, weight/distance conversion, active/pause/rest clocks, explicit completion, history and rest-day skipping.
- Water: canonical drink history, correction/undo, custom/auto-fit/fixed schedules, overnight windows, weekday choices, goal suppression and disabled-by-default new schedules.
- Reminders: Windows toast XML/actions, persisted occurrence/action history, snooze, quiet hours, category/individual system-sound choices, privacy controls, media mute, grouping, wake/backlog handling, diagnostics and a 60-second test.
- Spotify: external-browser OAuth PKCE, Windows-encrypted tokens, optional remote playback permission, devices/search/playlists and rate-limit/error handling. No embedded streaming claim.
- Voice: basic intents in five writing styles prepare a review action. Mutation waits for on-screen confirmation. Recognition quality still depends on the configured provider.
- Backup: standalone SQLite export/validated restore with rollback copy; existing settings/library files backed up before migration.

## Install and setup

Run `Agent Notch Setup 0.9.0.exe`. The unsigned installer may show Windows publisher warnings. Use the normal installer upgrade and close the older app when requested. No uninstall or data deletion is required for an upgrade. Login startup retains the existing saved choice. NSIS registers normal Windows uninstall; app-owned data is retained by default, with a separate confirmed cleanup option.

**Windows notifications are now enabled on this PC.** The packaged 60-second hidden-island test delivered, and the user confirmed its banner and sound. Enable and save your Water schedule separately; the test does not enable regular water reminders. Use Settings → reminder diagnostics/test and leave the tray process running. DND, Windows volume and app sound preferences still govern alerts. Fully quitting Agent Notch stops reminders.

Spotify requires your own developer Client ID, exact loopback redirect registration, browser consent and an eligible account/device. YouTube playlists require an optional YouTube Data API key; manual courses require none. Gemini Live retains its own Gemini API key setup in Providers and cloud-audio consent. A Groq key cannot authenticate Gemini or Spotify. The release never invents these credentials.

## Data and verification limits

Migration keeps original `settings.json`/`library.json` and copies them under `backups/before-productivity-v1`. New modules use `productivity.sqlite`. Export a backup before making large changes. To roll back software, retain the 0.9.0 database and backups; 0.8.0 cannot edit the new modules. Credentials are encrypted separately and excluded from routine exports.

See `manual-windows-qa.md` for executed tests and evidence. **NOT VERIFIED:** physical toast actions, other sound profiles/preview volume, lock/suspend/DND hardware behavior, live Spotify/YouTube/Gemini account requests, microphone recognition/insertion, actual multi-monitor/DPI hardware and interactive 0.9.0 install/uninstall. Core labels fit all five styles in the test app; advanced labels use English fallback and native-speaker/screen-reader review remains pending.
