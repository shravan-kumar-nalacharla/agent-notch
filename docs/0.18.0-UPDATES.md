# Agent Notch 0.18.0

Agent Notch 0.18.0 is the public Windows release from Huygen Studios. It fixes the three visible island problems and adds the release-note experience.

## What changed

- **Lyrics fit the card.** Only the current line and the line before it are rendered. The current line is 18px bold; the previous line is 13px faded. The third clipped row is gone, and the current line no longer enters from below the lyric area.
- **Chat is quieter.** The “Ask a question” heading and the empty-state paragraph are removed. The conversation and composer use the space.
- **The notch closes reliably.** Leaving the island closes it after the configured grace period. Focus in the chat input only holds it while you are actively typing (8-second keyboard window). Pinning, recording, capture, a running task or a manual terminal still hold it open.
- **What’s new is in Settings.** Settings → About shows the current release notes and the recent history, plus a link to the public update catalog.
- **Public website.** A static site at `https://shravan-kumar-nalacharla.github.io/agent-notch-site/` includes an interactive notch preview, install guide, SmartScreen guidance, checksum, FAQ and the full release catalog.

## Install and updates

Existing 0.17.1 installations need one manual 0.18.0 install because 0.17.1 has no updater. Builds 0.17.2 through 0.17.7 may not install automatically; install 0.18.0 manually if you are on one of them. From 0.18.0 onward, updates check shortly after startup, every six hours and from Settings, download in the background and require an explicit restart.

The installer is unsigned. Windows SmartScreen can warn. The website and release include the SHA-256 checksum; compare it before running.
