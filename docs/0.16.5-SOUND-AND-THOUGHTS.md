# Everyday sounds and visible thoughts — 0.16.5

Normal buttons, settings/menu selections and Enter submissions use the former soft mute cue (`mute.mp3`). Mute/unmute now uses the former main-menu cue (`open.mp3`). Hover stays quiet and separately configurable. Enter uses trusted, non-repeating, non-composing form input; multiline text and modified shortcuts are not turned into sound events. Native Enter activation of a submit button is throttled to one cue.

The recording-state race that silenced no-speech feedback is fixed: voice terminal events clear capture suppression before scheduling one error cue. Empty or rejected-empty recognition produces `code: no_speech` and "No speech detected. Please try again." It never calls the answer model or TTS for empty input. Generic voice errors also get one cue. Global off is labelled **Enable all app sound effects** under Appearance and blocks buttons, menus, Enter, mute, hover, errors, timer/notch reminders, Windows toast sounds and native reminder-sound previews. It stops any current app effect. Speech and music keep their own controls.

The actual profile already had automatic thoughts enabled. The previous 60-minute average made the randomized interval 45–75 minutes; acknowledgements existed but did not prove the user noticed a popup. The default average is now 45 minutes (about 34–56 randomized minutes), retaining eight per active day and startup/unlock behavior. The installed profile's previous default interval is shortened without resetting today's count or overwriting other thought preferences. Custom user intervals remain editable and preserved. Quotes stay offline in the existing curated library; no external API is needed.

Due thoughts reassert the existing topmost level and move above other windows without taking focus. A thought must survive its entrance and remain visible for 800 ms before its nonce acknowledgement can count; interrupted popups no longer immediately consume a slot. Acknowledgement rechecks the same DND, quiet-hour, lock, focus, meeting, fullscreen and daily-limit policy as selection. Five-second display time and the original pop-in/pop-out motion remain unchanged. Quiet Moments shows the next due time, today's count, average interval and the actual pause reason. Busy/voice/focus/locked/hidden/DND states still defer rather than being overridden.

Unit and Windows/Electron checks cover cue mapping, real Enter/button events, one no-speech cue after recording clears, persisted global off, silent Windows XML, empty-input model/TTS guards, schedule/status policy and interrupted acknowledgements. The existing outer motion/geometry files are hash-checked against 0.16.4. This does not claim a full-day physical observation or that a delivery acknowledgement proves the user's attention.
