# Agent Notch 0.25.0 — Nashi PDF actions

File Actions now handles PDFs locally through `pdf-lib`.

- Inspect page count.
- Merge multiple PDFs into one.
- Split every page into its own PDF in a chosen folder.
- Rotate 90°/180°/270°.
- Combine PNG/JPEG images into a PDF.
- Originals are never overwritten.

This begins the remaining Nashi tool port. Archive extraction, QR, metadata,
annotation/redaction, framing/collage, subtitles, web download and the full
media suite are still outstanding.

Verified: packaged 0.25.0 inspected a 2-page PDF, showed the PDF controls in
File Actions, and rotated it to 90°; unit tests merge two PDFs, split them and
rotate them.
