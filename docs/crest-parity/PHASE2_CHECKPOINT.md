# Core tools checkpoint — 0.14.0

This is a working subset of phase two, not completion of all 64 capabilities. Phase-one source commit: 7836d35. Original baseline: 5da942b. No new runtime dependencies were added.

Implemented: labelled notch Mute/Unmute; phase-one window/media/privacy reliability; persisted five-language code drafts with basic lexical coloring and export; offline unit converter; dated ECB currency reference rates; discovered Start-menu launcher and pins; timed Windows Keep Awake; selected/all-display screenshots with pixel crop and save/copy/Shelf; local Windows OCR search/highlight/copy; race-safe camera shutdown; encrypted multi-feed ICS calendar and cache with meeting Join; official GitHub contribution calendar and public-profile-only fallback; independent Anthropic/OpenRouter chat and streaming adapters; key-isolated DeepSeek balances and OpenRouter spending-limit metadata; on-demand hardware details and reviewed power-plan changes.

All 230 unit/regression tests pass. Source Electron checks: six phase-one checks, six workspace checks, 23 Settings/key-retention checks and 13 microphone/privacy checks. These use fresh isolated profiles and no real provider keys. The source media UI test uses fixture sessions. The separate native Windows test enumerated one actual media source, rejected a wrong-session command without changing playback, started/released Keep Awake, and completed Windows OCR in memory while the microphone remained blocked. Live ECB fetch returned 30 currencies dated 2026-11-03. Authenticated Anthropic/OpenRouter/GitHub and private calendar servers were not called.

Data: workspace-v1.json uses atomic saves and preserves unrecognized/corrupt versions. Clipboard history is memory-only. Calendar links and event cache move to the existing Windows encrypted integration store; legacy URL is removed only after successful encryption. Public library IPC never exposes private calendar URLs. HTTPS calendar fetching rejects private/nonpublic DNS answers and pins the chosen public address, with no redirects, limited responses and bounded timeouts. Nothing in screenshots/local OCR is uploaded. Captures live in memory until the user explicitly saves or copies them.

OpenRouter ordinary-key metadata is labelled as a key spending limit, never an account balance. Account-wide credits require broader management-key permission and are not requested. GitHub without a token opens the public profile only; no invented contribution data is displayed. Hardware temperature/power/VRAM/FPS stay explicitly unavailable without a supported provider.
