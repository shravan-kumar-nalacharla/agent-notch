# Code provenance

Crest is a read-only feature reference. New product code is independently authored for Agent Notch, preserving its Electron shell, Windows helper and domain services. No Crest source, branding, executable or dependency tree is imported. Existing Voice Flow, Nūs, Bloom, Electron, Playwright and .NET notices remain applicable. New dependencies must carry their own notices. Full source and a reviewable diff accompany each release.
