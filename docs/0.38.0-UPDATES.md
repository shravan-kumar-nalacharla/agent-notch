# Agent Notch 0.38.0

Fresh settings enable the global dictation hotkey and allow audio uploads to the selected speech provider. Recording still requires an explicit action and a configured provider; saved opt-outs are respected.

Right-click no longer opens Settings. Settings, thoughts, general reminders and hydration reminders share the notch's saved palette and fonts. Save-status labels use clean text. The redundant navigation strip above More Tools is removed. Quick Access interpolates wheel movement instead of jumping directly by the wheel delta.

The palette retains the chosen accent and derives a readable display color when it would disappear against the surface. Controls choose black or white ink by contrast. Black and white accents remain usable on both dark and light themes; neutral accents produce neutral corner glows.

Global dictation replaces the expanded panel with the listening HUD even when pinned, keeping the interface clear of the spectrum. Thoughts and reminder backgrounds animate with their content on entry and dismissal, with reduced-motion support.

The full assistant component bundle is deferred until the notch opens or dictation begins. Settings and File Studio allow background throttling; both windows are destroyed on close. No forced working-set trimming or restrictive heap cap is used.

Electron's performance guidance recommends deferring expensive initialization. Microsoft distinguishes private allocations from resident working sets, and recommends reducing background work. These changes do not establish a universal 100–150 MB maximum: measurement must cover idle, normal interaction and audio/video use separately.

Sources: [Electron performance](https://www.electronjs.org/docs/latest/tutorial/performance), [BrowserWindow background throttling](https://www.electronjs.org/docs/latest/api/browser-window), [Windows memory guidance](https://learn.microsoft.com/en-us/windows/apps/develop/performance/disk-memory), [Windows working sets](https://learn.microsoft.com/en-us/windows/win32/memory/working-set).

## Verification and measurement

The packaged app passed 26 checks across the shared-surface, layout and Astryx suites. The unit run passed 332 tests with two GUI-dependent tests skipped; the corresponding interface paths were exercised in the packaged checks. Physical microphone/camera capture and paid provider calls were not exercised.

On this machine, GPU-enabled packaged profiles measured 207.4 MB of Electron private allocations at idle for 0.37.0 and 189.7 MB for 0.38.0. Home measured 234.0 MB versus 227.2 MB. Settings measured 335.2 MB versus 339.4 MB, so opening Settings did not show an improvement in that sample. These are individual samples, not a universal memory ceiling, and exclude the native helper and separately launched managed browser. Working-set totals are recorded separately because they can count shared pages more than once.

The 100–150 MB target is not reached. GPU resources and Electron's browser/renderer processes remain significant consumers; forcing working-set eviction would change the visible number without eliminating allocations. Raw profiles and screenshots are saved with the local build resources.
