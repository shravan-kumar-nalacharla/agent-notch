Private desktop build, 2026-11-02. Installer and evidence: `F:\AgentNotch-builds\0.6.2`.

## Reference analysis

The supplied `C:\Users\shrav\Downloads\animation guide.mp4` is 44.533 seconds, 1920 × 1080, 60 frames/second, 2,672 frames. Every frame was decoded and indexed, with a crop thumbnail, timestamp and approximate dark-silhouette measurement. All frames can be stepped through in `F:\AgentNotch-builds\animation-analysis\index.html`; `frames.csv` and 34 contact sheets preserve the full sequence. Transition contact sheets were visually reviewed. The silhouette threshold can merge into wallpaper/desktop pixels, so those measurements are not claimed as exact UI dimensions.

Observed reference behavior:

- Frames 219 onward (~3.65 seconds): the small top shape grows downward and outward, then settles; content fades in after expansion starts. It does not create a new native window on hover.
- Around frames 343–364 (~5.72–6.07 seconds): Media and Focus crossfade with horizontal movement. Other tool changes follow the same visual language.
- Around frames 944–981 (~15.73–16.35 seconds): content retreats and the shell contracts toward the top.
- Later: clock-to-eyes, cyan/violet light, sleeping and greeting states. Sleeping/greeting states were deliberately omitted per the user's request; periodic original quotes replace that behavior.

The video is a Nusa-style reference, not proof of Bloom's runtime. Bloom's source was separately inspected at commit `8a8d6a9cf214c379dd6cb32746f6cecbc23e2e9e` (3.10.1). Its React/Tauri implementation uses independent spring presets for width (400 stiffness / 31 damping), height (450 / 29), and vertical motion (550 / 45 / mass 0.8). Those presets are adapted in the existing DOM renderer with native Web Animations; the app remains integrated with the current Electron/native backend. Attribution and the GPL-3.0-only license are retained.

## Changes

- Top-origin slide/zoom and independent width/height spring settling, about 700 ms opening and 440 ms closing. Native bounds remain stationary. Content fades in separately, and carousel arrows animate horizontal transitions.
- Two causes of missing/choppy movement were found: global reduced-motion CSS disabled transitions even with explicit Standard selected; and Electron throttled the visible but unfocused island. Standard/Subtle/Off remain selectable. The island now sets `backgroundThrottling:false`, while dormant eye/glow animation is stopped/hidden.
- The final gradient is a soft inner glow at 18% opacity. It fades inward over 38–44 pixels from every edge, without a hard outline. A fixed color texture rotates slowly; no gradient stops are animated. The old header rectangle, border mask and colored outer shadow are removed. The glow is pointer-transparent and also covers quote/voice presentations. All Features is last in the bottom menu and opens the grid directly; Focus Time has a single bottom-menu entry and is omitted from that grid.
- Quotes now have a scheduled first attempt after eight seconds and periodic checks thereafter. Default: all day, five-minute interval, up to 48 per day, eight-second display. An idle quote appears as a small 330 × 92 card and folds away. Interval, cap, category and DND remain configurable. Voice, focus and hidden/fullscreen/Settings states suppress delivery; suppressed attempts are not recorded as shown. Original unattributed text is used, not fabricated philosopher quotations.
- Settings → Voice includes a companion name (default Cutie), optional local “hey + name”, six Groq Orpheus voices, installed-voice fallback, Save & hear voice, and recognizer status. Wake listening is off until enabled. It uses the default Windows microphone and installed English recognizer, not a downloaded wake model. Reply audio pauses wake detection to avoid self-triggering. After greeting, in-island chat listens and submits after speech ends; system dictation remains separate.
- Natural speech uses the official Groq Orpheus API (`canopylabs/orpheus-v1-english`, default Hannah). Long replies are split at its 200-character limit. Audio is played from temporary memory blobs, and Stop cancels playback. No voice-model weights are installed.
- Screen guidance now uses native Windows OCR/UI Automation and grounded references. Python/Klyro runtime files are no longer packaged. Targets are checked again before an explicit click; native click coordinates account for display scale.
- The user's “Object has been destroyed” exception was traced to a late `window:hitbox` event accessing a closed BrowserWindow. Shared live-window/sender guards, shutdown guards, and renderer cleanup now reject those late events safely. No global error-swallowing handler was added to production.

The 0.6.1 correction starts an expanded panel from the current quote card geometry and prevents quote expiry from shrinking the active panel. The focused experience check waits through expiry to verify this. Voice chat also receives the configured companion name.

## Storage

Before: 694,029,978 unpacked app bytes. New build: approximately 423,260,656 bytes, about **39% smaller**. Final byte counts are recorded with release evidence. The compressed native helper is about 75 MB rather than 180 MB, and the ~119 MB Python screen runtime is removed. Installer compression means the installer itself shrinks by a different percentage. User profiles, research inputs and .NET/OS caches are not included in this comparison. Electron remains the main fixed footprint; this is not a claim of a tiny native-only app.

## Verification and limits

- 64 Node tests passed, including spring trajectories, quote timing/caps, voice segmentation/HTTP/audio validation, native grounding/revalidation, and destroyed-window trust guards.
- Source, packaged and installed compact smoke tests cover layout, existing widgets, navigation and Settings. The previous 0.6.1 packaged suite passed 42 checks. The 0.6.2 packaged suite passes 45 checks, adding menu order, duplicate-removal and Focus Time selection checks. A separate navigation check verifies the grid is visible, the Home page is hidden and the Focus Time shortcut opens the timer. Hardware reference captures from 0.6.0 are historical and show the superseded border glow. The current inner-glow screenshot is evidence/spring-focus.png.
- Six focused Settings visibility/hit-target tests pass: Standard/Subtle/Off with normal/reduced OS motion.
- `evidence\experience.json`: real scheduled startup quote, intermediate reveal sizes, small height overshoot, centered animation, soft inward glow and rotating texture, carousel movement and gradual collapse, on one Windows 11 display at 125%. This focused capture uses software rendering for deterministic snapshots.
- `evidence\background-motion.json`: hardware-enabled, visible but unfocused comparison. Background throttling produced 7 RAF samples; disabled throttling produced 51 over the same approximately 1.2-second opening test. This is bounded evidence on this machine, not a universal 60fps guarantee.
- `evidence\native-experience.json`: native Windows OCR returned visible lines, UI Automation returned controls on one run and safely timed out to OCR on another. The local recognizer accepted a Windows-generated synthetic “hey Cutie” at about 0.98 confidence. This did **not** use a microphone and is not a physical wake-word accuracy test.
- `evidence\island-motion-demo.mp4`: local hardware-enabled recording with a controlled gray backdrop. Recording affects timing; capture FPS and RAF metrics are reported separately, including the initially poor capture samples. The recording is not presented as a frame-rate benchmark.
- The external Groq voice test could not decrypt the saved credential in its test context, so no live Orpheus success is claimed. Use Settings → Voice → Save & hear voice with a valid Groq key. Mocked service contracts passed. Physical wake/microphone/cross-app insertion and a paid LLM conversation remain manual checks.
- `evidence\source-parity.json`, packaged/installed smoke logs, installer hash and upgrade-retention evidence verify the actual delivered artifact. Personal settings/library/token files are backed up privately outside the release directory. Existing QA uninstall tests from 0.5.0 are not relabeled as a new full 0.6.0 uninstall test.
- Windows 10, physical mixed-DPI/multiple monitors, suspend/resume and long-duration microphone accuracy remain untested. The installer is unsigned. The build is for the user's private desktop use; Bloom's attribution/license accompanies adapted material.
