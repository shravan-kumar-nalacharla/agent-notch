# Agent Notch 0.5.0 — changes, audit and acceptance

Release candidate, 2026-11-02. Canonical source: `C:\Users\shrav\Downloads\TwoCode-Windows\TwoCode\island-fusion`. Build/evidence: `F:\AgentNotch-builds\0.5.0`. This is an integrated change to the existing app, not a separate prototype or a claim that every reference product has been reproduced.

## Delivered behavior

- Idle: faint 100 × 2 DIP top-center line; no robot/eyes/background card. Hover intent defaults to 100 ms. A click or the existing open shortcut also opens it.
- Default panel: 470 × 250 DIP. Compact 410 × 230 and roomy 540 × 280 are selectable. Explicit lyrics expansion uses at most 315 DIP height before responsive screen caps. Bottom navigation remains available.
- One stationary native transparent envelope surrounds the card. CSS opacity/scale/vertical movement handles reveal/collapse; normal view switching does not resize/move the native window. Pointer positions outside the visible card enable native ignore-mouse-events. Floating mode has independent position persistence.
- Cancelable one-second close grace, input/drag/voice/pin guards, reduced-motion settings. Eyes blink organically only while visible; gaze and blink use separate transforms.
- Focus Time and Stopwatch use a steady red SVG arc. Ticks update text and arc, retaining the same ring DOM node. Runtime timing uses a monotonic anchor, and persisted snapshots use wall-time timestamps.
- Media transport and thin neutral sliders remain. Lyrics report typed outcomes, include album/duration in exact lookup, safely score fallback matches, cache results, respect rate limiting and abort track changes. Political commentary does not receive fabricated lyrics or a generic connection error.
- Optional offline Quiet Moments use original unattributed text, morning/evening windows, daily cap/cooldown/recent exclusion, dismiss/favorite controls. They do not open the island or interrupt recording/focus.
- Official DeepSeek assistant and cleanup support, streaming/cancellation, token diagnostics, thinking/model controls and Save & Test. DeepSeek is excluded from transcription/vision selectors; screen guidance has its own provider.
- Assisted NSIS installer, real registered uninstaller, Settings uninstall action, keep-data default and explicit erase option. Removal cleans only exact-token-owned local Claude hooks. Updates skip hook/data removal.
- Native GPU WMI collection moved off the audio/hotkey message thread to a single background task with cached results. All existing voice, clipboard, shelf, assistant, agent and utility routes remain.

## Reproducible baseline findings

The preserved 0.4.0 sources are under `build/baseline-0.4.0/src`; original installer remains in `dist-v0.4.0`.

| Evidence class | Finding and source |
|---|---|
| Static, confirmed | `main.cjs:53–54` requests up to 644 × 440; `renderer.js:6` sets every page height to 440. This directly accounts for oversized content. |
| Static, confirmed | `main.cjs:72–73` changes native bounds immediately on open and after 340 ms on close, while CSS independently animates geometry. Multiple coordinate/transform authorities make drift plausible. |
| Runtime, not reproduced | On the actual single 125% display, baseline frame capture did **not** reproduce a left/right jump. Baseline center drift was zero in that run. The native/CSS race is a source-level risk, not a proven cause of the user's specific jump. |
| Static, confirmed | `widgets.css:164` uses a conic-gradient timer; `widgets-ui.js:64,88–92` constructs the ring through `innerHTML`. There is no evidence that the mascot pulse animation caused the timer problem. |
| Runtime, bounded | Updated source and packaged smoke record center deviation about 0.6 DIP, below the 2 DIP threshold, during opening on this display. This does not establish physical mixed-DPI/multiple-monitor behavior. |
| Static and tested | `widgets-ui.js:158` flattened lyric failures into a connection message. New typed outcomes distinguish absent lyrics, non-music and network/service failures. |
| Static, confirmed | The original Klyro client contains a third-party relay. Agent Notch's integrated worker imports capture/OCR/UIA/grounding, not that relay client; main assistant calls use `src/providers.cjs`. |
| Static and measured | Synchronous GPU WMI ran on the Windows Forms message thread. Moving it to a background task removes that blocking path. Warm native system requests measured 142–455 ms; first startup request was 8,609 ms. This is not a general latency/FPS guarantee. |

A private encrypted-data backup is retained separately under `F:\AgentNotch-builds\private-upgrade-backup-0.5.0`; do not redistribute backups or user profiles. ## Documentation and feature scope

The user guide describes the new controls. `FEATURE-COMPLETION.md` retains the reference-product inventory and explicitly incomplete peripheral features. Offline ASR/local models/wake word, Codex/Cursor session monitoring, speech-following teleprompter, mobile/WhatsApp automation and full calendar recurrence are not newly implemented or presented as finished. Existing controls are preserved; public release should wait for the untested hardware/API cases and redistribution clearance.
