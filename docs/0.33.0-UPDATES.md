# Agent Notch 0.33.0 — cross-application workflows

The task coordinator no longer selects one route for a mixed request. A request such as “Open Chrome, go to YouTube … then open File Explorer and navigate to Downloads” is split into a browser workflow and a Windows workflow. Each runs through its existing executor, reports its own result, and the overall task reports partial completion if one branch fails. Branches are serialized for foreground-input safety rather than run concurrently.
