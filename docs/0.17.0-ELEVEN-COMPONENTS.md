# Agent Notch 0.17.0

All 17 requested ElevenLabs components are now adapted from the actual MIT registry sources, pinned in ui/eleven/SOURCES.json.

| Component | Application use |
|---|---|
| Audio Player | Windows media transport, playback status and clock |
| Scrub Bar | Pointer and keyboard timeline, one native seek on release |
| Waveform | Recent system output levels in the media timeline |
| Bar Visualizer | Native microphone, assistant output and system output meters |
| Conversation | Independently scrolling chat and voice answer |
| Message | Chat message layout |
| Response | Streaming safe Markdown, no raw HTML or remote image requests |
| Conversation Bar | Chat composer and stop-response control |
| Speech Input | Native voice typing into chat |
| Live Waveform | Native dictation HUD and composer |
| Mic Selector | Native Windows input devices; no browser capture |
| Orb | Original shader with native WebGL2 adapter |
| Voice Picker | Saved Sarvam voice selection |
| Voice Button | Listen/processing states through existing privacy gate |
| Matrix | Assistant processing visualization |
| Shimmering Text | Assistant processing label |
| Transcript Viewer | Collapsible untimed transcript; no invented timestamps |

Music controls remain mounted across metadata updates. Play/pause stays visible; lyrics scroll separately. Browser sessions show track names, and controls carry the displayed session and title so stale seeks are rejected. Carousel swipes ignore sliders and scrub bars. Only media sessions exposed by Windows can appear; browsers may expose fewer sessions than their open tabs. Output bars describe system output, not decoded track FFT data.

Native capture, Sarvam/Gemini routing, mute, push-to-talk and existing outer island motion remain in place. No new microphone stream or ElevenLabs service is added. Partial voice preference saves preserve the companion name.

Includes the 0.16.5 sound/quote changes: softer daily-use cues, Enter matching menu clicks, mute/menu cue swap, no-speech error cue, master effects off and live quote schedule diagnostics. Automatic thoughts default to startup plus randomized 45-minute intervals, up to eight daily, respecting quiet hours, DND, calls, focus and microphone use. Existing custom schedules are retained.

Validation evidence is stored outside the repository under D:/AgentNotch-builds/0.17.0. Provider credentials and personal profile data are excluded from distributable QA artifacts. Tests use synthetic provider events; real conversations and listening quality require user verification.
