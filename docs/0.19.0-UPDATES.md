# Agent Notch 0.19.0

Agent Notch 0.19.0 starts the file, agent-face and offline-speech work while fixing the two regressions reported after 0.18.0.

## Fixed

- **Saved API keys are removed on uninstall.** A small uninstall-time script strips `keys`, integration secrets and the local agent token even when the user chooses to keep notes and history. The provider keys live in the user profile, not in the installer; the installer is now verified to contain no key material.
- **Lyrics no longer re-animate per word.** The legacy media fallback now renders only the current and previous full lines and repaints only when the line changes. The primary Eleven surface already renders only two full lines. The current line slides in once, then stays still while it is current.
- **The notch closes reliably** and the chat intro removal from 0.18.0 remains.

## Added

- **Agent Face.** Settings → Appearance now has a deterministic blob companion: organic, round, squircle, droplet or hexagon; hue; idle, happy, curious, sleepy or love; live preview. It replaces the eyes only when enabled, stays inside the face area and reacts to a click. Clicking the status/face still opens the island.
- **File actions (first slice).** All Tools → File actions accepts a dropped or chosen image, shows dimensions/size, converts PNG/JPEG and optionally resizes to a new file. The original is never overwritten. Video, audio and document tool packs are specified in the PRD for the next phase.
- **0.19.0 PRD** covering the Nashi file model, Blobatar-shaped agent face, Rune/Astryx evaluation, Handy/Whisper offline speech model sizes, resource budgets, security rules and phase acceptance tests. [PRD](0.19.0-PRD.md)

## Explicitly not claimed

- Offline Whisper/Parakeet transcription is not bundled in this build. The model packs are 150 MB–1.6 GB and need a separate hash-verified download and native helper.
- Video/audio/document conversion and full crop/trim editors are phase 2. Only image conversion is in this build.
- Rune is not a runtime dependency; replacing Electron with a pre-release Rust framework would discard the existing native/IPC/browser stack.

## Updates and data

Automatic updates keep working from 0.18.0: check after startup, every six hours and manually; download in the background; explicit restart; profile retained. Existing 0.18.0 installs can update in place. 0.17.1 and older need one manual install.

The installer is unsigned. Verify `SHA256SUMS.txt` and `latest.yml`; the stable alias is `Agent-Notch-Setup.exe`.
