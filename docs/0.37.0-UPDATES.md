# Agent Notch 0.37.0

Chat uses a simple rounded composer with its microphone and send controls inside. The composer is anchored above navigation; the conversation occupies the remaining space. Compact, Medium, Large and Auto layouts are checked for containment and a stable bottom edge.

Legacy checkbox styling is excluded from Astryx switches. Their real input has a correctly aligned hit target, visible on/off states and press feedback. Input and selector focus transitions to a slightly lighter surface instead of showing nested outlines. Labels are extracted without hidden dropdown options.

Appearance contains one global size preset, with custom width and height still available. The old per-tool picker is removed. Settings and the full tool list scroll faster than chat and voice content. Unchanged size notifications are ignored during a resize.

The notch and File Studio share the saved accent palette and fonts. Adjacent hues fade into corners after the black surface appears. Dictation has animated entry and exit, a live spectrum and a transcription state, including when the notch is already expanded. The media volume row has reserved visible space.

See [the performance investigation](0.37.0-PERFORMANCE.md) for the memory, package-size and Tauri findings. UI checks cover repeated pointer toggles, focus styling, global sizes, chat anchoring, media volume, theme changes, the voice graphics lifecycle, scrolling and the dictation HUD. Paid provider calls and physical microphone/camera capture are not part of those automated checks.
