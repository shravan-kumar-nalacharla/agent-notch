# Agent Notch 0.4.0

## Confirmed causes and changes

- **Clipped chat after voice:** `window:voice-hud(false)` unconditionally shrank an expanded native window. `main.cjs` now tracks expanded state and preserves its bounds when a voice session ends. Chat has a flexible conversation area, a visible composer, hidden scrollbars and a collapsible last-transcript section. System dictation no longer navigates to chat after insertion.
- **Moving, uneven island:** the native 16 ms bounds animation competed with CSS width transitions; content widths were anchored to the window's left padding. The native window now reserves its envelope once, CSS handles the centered silhouette, and native shrinking waits for the close animation. All expanded pages use the same 644 × 440 DIP envelope, clamped to the display. Floating placement preserves its center. Eyes stay at the header's center and use rounded 10 × 12 DIP shapes.
- **Slow waveform:** the native level-event emitter ran inside a 200 ms system timer. Active recording now samples at approximately 30 Hz while idle polling remains at 200 ms. Wave bars animate transforms instead of layout heights. This is an implementation change, not a measured 60 fps guarantee.
- **Lost navigation:** Tools explicitly hid the shared dock. That rule is removed. Settings > Island has checkboxes for up to eight extra tool shortcuts. The core Home, Assistant, Notes, Focus Time, Tools, Agents and Settings buttons remain available.
- **Duplicate focus tools:** the old Focus page is removed; its dock shortcut opens the existing Pomodoro layout, now named Focus Time. Custom focus duration, breaks and countdown remain. Stopwatch mode counts upward with persistent start/pause/resume/reset state independently of the countdown.
- **Shelf removal:** each file tile has a remove button, with Clear shelf for all references. All files are reachable, rather than only the first seven. Originals are never deleted.
- **Clipboard:** opt-in local history holds up to 500 text entries, with previews, Copy feedback, individual Delete and Clear history. Existing exclusions remain. Atomic library writes retry brief Windows sharing violations, reproduced during the history-cap test.
- **Settings:** a fixed Save changes bar is accessible from every section and reports Saving, Changes saved, Unsaved changes and failures. Voice and dock preferences use the same validated save operation. Diagnostics uses text nodes for window titles and other native results.
- **Hydration:** automatic cadence divides active hours across the configured daily goal/bottle servings. Custom intervals remain available. Enabling schedules the next drink reminder; reaching the goal stops reminders. Existing saved custom intervals are preserved. Notifications say to drink water. The UI shows the cadence and active hours; undo is available.
- **Media:** polling updates the transport icon even while its button has focus. It updates position and controls without replacing the entire player each second. Sliders are thin and neutral. Unsupported transport commands report errors.
- **Lyrics:** metadata cleanup, exact title/artist/duration lookup, ranked fallback, caching, client identification, and Retry-After handling follow [LRCLIB's API](https://lrclib.net/docs.txt). Synchronized lines stay small, follow playback, and seek when clicked. Instrumental/unavailable/offline states are explicit; arbitrary videos and trailers may have no lyrics.
- **Teleprompter:** Start uses the current editor text, saves it and scrolls immediately. Fractional scroll distance accumulates across frames, fixing rounding that prevented slow scrolling. Preview, pause, reset, speed, type size and mirrored text work in one panel.
- **Mirror:** the video crop is a square, with a larger usable preview and camera lifecycle cleanup.

## Validation

- `npm test`: 47 tests passed, including clipboard capacity/deletion, stopwatch persistence, goal-based hydration scheduling, shelf reference safety and lyrics lookup/cache/rate-limit behavior.
- Both source and packaged Electron `--smoke-test` passed on Windows (packaged exit 0). All 36 source files match the packaged archive; static installer extraction also matched app.asar and the rebuilt native binary. Tests include all existing baseline widget checks and the new chat bounds, fixed geometry, dock, shelf removal, clipboard controls/deletion, counting/pausing stopwatch, square mirror, newly typed teleprompter scrolling and settings save/favorites flows.
- Media icon state was tested with a controlled native-media fixture, including focus remaining on the play/pause button. It is not proof of every external player's transport behavior.
- Live LRCLIB request for a public sample track returned both synchronized and plain lyrics. Lyrics text was not recorded in the test output.
- `npm run build:native`: produced the Windows native helper. Packaging prepares and probes the bundled OCR/UI Automation runtime.
- Screenshots: `artifacts/polish-chat.png`, `polish-prompter.png`, `polish-stopwatch.png`, `polish-settings.png`, plus the existing carousel captures. Packaged smoke captures go under `%TEMP%/agent-notch-smoke`.

## Still requiring real-world validation

Live speech-to-text and insertion into Codex, WhatsApp and Discord were not exercised in this pass. The existing Ctrl+Shift+Windows chord is preserved; protected/elevated fields and changed focus still use the safe fallback. Physical microphone, hardware acceleration performance, actual hydration toast delivery, mixed-DPI/monitor transitions and clean-machine installer/uninstaller testing remain manual checks. The installer remains unsigned, and the existing Klyro redistribution/license issue remains unresolved for public distribution.
