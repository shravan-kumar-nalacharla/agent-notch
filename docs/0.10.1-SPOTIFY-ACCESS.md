# 0.10.1 — Spotify authorization status

The user's browser reached the registered loopback callback, while Spotify denied the profile/API request with HTTP403. The user confirmed that the developer-app owner has no Premium subscription. Spotify's current development-mode rules require the app owner to have Premium; signing into OAuth does not by itself establish Web API access. An allowed login may still receive403 if its user is not on the developer app's allowlist.

## App defect and fix

0.10.0 saved the token response before verifying `GET /me` and defined Connected from the presence of a refresh token. When the subsequent profile request failed, the browser displayed an authorization error while the app still displayed Connected. Its generic403 message did not identify the failed verification step.

0.10.1 now:

- Reports Connected only after a successful profile response with a usable account identity.
- Keeps a newly exchanged token in memory while verifying; saves the successful session only after verification. Failed completion clears incomplete credentials and reports an account-access requirement.
- Recognizes old saved sessions with no verified account as incomplete after restart, blocks playback/API requests for them, and keeps Disconnect/Reconnect available.
- Distinguishes finishing sign-in from account access not verified. Recovery setup opens automatically for incomplete sessions; playback controls stay hidden.
- Returns a clear403 explanation in the callback page for profile access denial, without echoing authorization codes or tokens.
- Accepts current `account_id` as well as the older `id`; a missing/deprecated subscription field is not assumed to mean Free.

No redirect change, Client Secret or new API key removes Spotify's developer-account eligibility requirement. Agent Notch does not bypass it. No account credentials were read from the user's profile, no subscription was purchased, and no live Spotify account calls were made during the patch tests.

## User recovery

To use the Web API integration, ensure the developer-app owner has Spotify Premium. In the [developer dashboard](https://developer.spotify.com/dashboard), check the app's Users Management allowlist for the account being authorized. Install0.10.1, choose Disconnect to remove the incomplete session, then Connect and complete browser sign-in. Keep the registered URI `http://127.0.0.1:43857/callback`.

If keeping Spotify Free, the existing Agent Notch Media widget uses Windows media sessions when Spotify desktop exposes them. That path does not require this developer OAuth integration; available controls remain subject to Spotify's player behavior. This was not live-tested against the user's Spotify session.

- **151 unit/integration tests passed.** The three new cases cover a real local callback returning profile403 with no saved partial session, connection status while verification is pending, current `account_id` without `product`, and old incomplete credentials after restart.
- **Six source Windows UI checks passed:** incomplete and pending labels, reset buttons, expanded recovery setup, hidden playback controls and disconnected state. Fixtures use no real credentials or cloud requests.
- Packaged Spotify, productivity and notch checks plus byte verification are recorded in `artifacts/0.10.1/release-verification.txt`. The0.10.0 reminder implementation is retained; this patch targets Spotify OAuth/status behavior.

Final packaged results: six Spotify access checks,11 notch flows (zero Windows toasts),12 productivity checks and15 Settings save/scroll checks passed. All91 source files and seven native resources match the reviewed files. Comparison with0.10.0 confirms the notch/tracking code and GIFs are byte-identical; changed app files are Spotify backend/UI, preload version and the smoke-test entry point, plus the new Spotify UI check.

Not verified: live Spotify access/playback after the user meets provider requirements, physical interactive install/uninstall and account eligibility in the provider dashboard. The installer is unsigned.
