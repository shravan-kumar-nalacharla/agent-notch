# Agent Notch 0.38.1

Quick Access now scrolls horizontally with mouse-wheel or trackpad input and wraps in both directions. Native mandatory snapping is disabled so it cannot undo each small animation step. The add button sits outside the scrolling items and remains available at every position, including compact sizes.

Three visual copies provide a continuous seam while retaining one saved list. Repeated items keep their open, remove, context-menu and drag handlers; duplicate buttons are excluded from keyboard tab navigation. No new file is added merely by looping. When all items fit, the row shows a single copy without unnecessary scrolling. Reduced-motion mode moves immediately.

Background settings updates do not rebuild an unchanged Quick Access list, preserving its scroll position. Resizing recalculates the loop and leaves the add control visible.

Validation covers real Chromium mouse-wheel input, intermediate animation frames, repeated scrolling in both directions, horizontal trackpad input, handler preservation, compact sizing and reduced motion. File dialogs and launching users' files are not automated by this check.
