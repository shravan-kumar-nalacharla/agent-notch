# Agent Notch 0.22.0 — documents

File Actions now covers documents in addition to images, video and audio.

- DOCX, DOC, ODT, RTF, TXT, PPTX, XLSX and CSV convert to a new PDF.
- Uses installed LibreOffice (`soffice.exe`), found on PATH, in the standard Program Files locations, or via `AGENT_NOTCH_SOFFICE`.
- No LibreOffice binary is bundled; the installer stays under 1 GB.
- Original is never overwritten.
- Packaged test: generated DOCX → 35,717-byte PDF with a valid `%PDF-` header.
- `npm test`: 296 tests, 296 passed.
- Installed update **0.21.0 → 0.22.0** passed discovery, download, silent install, relaunch and profile preservation.

Groq remains the default assistant/transcription provider; Local (Windows, offline) remains the no-key alternative. Whisper/Parakeet model packs are still separate.
