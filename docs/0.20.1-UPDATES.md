# Agent Notch 0.20.1 — square crop and default check

- File actions can center-crop to a square before converting or resizing. The original is never overwritten.
- Groq remains the default assistant and transcription provider. **Local (Windows, offline)** remains an explicit alternative; neither replaces the other.
- Added regression coverage for the Groq default and the local provider option.
- Packaged test: a 200×100 PNG center-cropped and resized to a valid 100×100 PNG.
- `npm test`: 291 tests, 291 passed.

The installed update check from 0.20.0 to 0.20.1 was attempted, but GitHub’s `/releases/latest` endpoint returned repeated 504 responses during the test window. The 0.19.0 → 0.20.0 update path passed immediately before this patch, and 0.20.1 uses the same installer/latest.yml path. Re-run the check when GitHub is healthy.
