# Resource investigation and decision

Agent Notch retains Electron in this release. The existing React UI, native Windows engine, plugins, browser automation, microphone privacy, clipboard handling, transparent window hit testing and File Studio remain available.

## Changes made

- Astryx controls use a single React root and shared theme per window, with portals into the existing forms. Removed controls are released instead of retaining individual React roots.
- The voice orb mounts only while its panel is visible. Leaving the panel destroys its graphics resources and WebGL context. The lifecycle is covered by the UI checks.
- Settings load a separate 1.16 MB component bundle instead of the full 1.73 MB assistant/media bundle. These are JavaScript file sizes, not RAM savings.
- File Studio loads the PDF viewer only when editing a PDF. It destroys an earlier PDF document before loading another.
- UI build dependencies are kept out of the runtime package. Astryx's required CSS is copied into the app by the UI build. Source maps and TypeScript declarations are excluded from packaging.
- Repeated identical layout notifications no longer restart a resize animation. The old continuously composited companion glow is disabled; the new theme glow uses bounded corner layers.
- Periodic timer, clipboard-enable and media-preference checks use lightweight state reads. They no longer clone the complete history and clipboard-image snapshot just to read a flag. A regression check verifies that 1,000 such reads perform no structured clones and return isolated values.

## Reading the measurements

The profile script records Electron processes separately and totals private bytes and working sets. Summing working sets can count shared Chromium pages more than once. Task Manager's grouped memory figure and Electron's private-byte figure are different metrics. The native Windows worker and a separately launched managed browser also need to be considered when measuring complete feature use.

Initial development profiles varied when the audio service started after UI feedback. They do not establish a reliable percentage reduction in overall RAM. This release does not claim that a 500 MB session has become a fixed smaller number, and it does not force working-set trimming or impose a JavaScript heap cap that could break large files. The reproducible profile is available with `--smoke-test --resource-profile`; results are stored with the build's verification artifacts.

The 0.36.0 archive included approximately 26.9 MB of Astryx source/package files and 25.7 MB of Lucide package files, even though the runtime already contained the compiled UI. Those build-only dependencies are removed from the new runtime. Managed Chromium and the self-contained Windows worker remain because removing them would remove offline capabilities. Local portable builds can share the existing managed browser runtime inside Agent-Notch-Resources; normal distribution builds still include it.

## Why this is not a Tauri rewrite

Tauri uses a Rust core and Windows WebView2. Its application package can avoid bundling Electron's Chromium runtime, but it remains a multi-process webview application. Moving this app requires replacing its Electron-specific IPC, window geometry/click-through handling, shortcuts, capture overlays, updater, protected storage, clipboard and process lifecycle integrations. The React interface and native worker could be retained, but that is a migration with a substantial regression surface, not a configuration change. It would also retain the managed browser used for automation.

The immediate decision is to fix and measure the existing application before considering that migration. No current feature has been removed to obtain a smaller number.
