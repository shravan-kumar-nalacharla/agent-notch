# Agent Notch 0.23.0 — local Whisper option

- Adds **Local Whisper base.en** to the dictation provider list when `openai-whisper` is installed.
- Groq remains the default assistant and transcription provider. Local (Windows) and Local Whisper are explicit no-key alternatives.
- Whisper writes a temporary WAV, runs the installed CLI with `base.en`, returns text, and deletes the temp folder. Audio stays on the PC.
- The model is not bundled. The cached `base.en` model is about 145 MB.
- [src/local-whisper.cjs](src/local-whisper.cjs)
