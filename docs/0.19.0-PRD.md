# Agent Notch 0.19.0 PRD — files, agent face and offline voice

Status: approved for phased implementation. This is a product/architecture plan, not a claim that every phase is complete.

## Product direction

Agent Notch stays a small, local-first Windows island. The next release adds three capabilities without turning the notch into a full desktop editor:

1. **Reviewed file actions** — drop or choose a file, see what it is, then convert or make a small edit.
2. **Agent face** — a deterministic blob companion that can be customized in Settings and shown instead of the two eyes.
3. **Optional offline speech** — a local transcription path for users who do not want a cloud key, delivered as an optional model pack.

The installer must stay under 1 GB. Optional heavy tools and models are downloaded on explicit user action, verified by hash, and stored outside `app.asar`.

## Analyses

### Nashi (`orkunisitmak/nashi-app`, MIT)

Nashi is a macOS-first Swift app with a Windows/Tauri port. It uses a drag-and-wheel interaction, supports image/PDF/audio/video tools, and downloads large external tools (FFmpeg, ImageMagick, LibreOffice) at first setup with hashes. Its wheel is a good interaction for a desktop app, but it does not belong in a 470 DIP notch.

**Decision:** do not copy the wheel or the Nashi source. Build an Agent Notch-native **Reviewed File Actions** card: file identity, one recommended action, a small set of alternatives, a preview, and an explicit Run button. Use the same *trust model* as Nashi: local tools, explicit review, hash-verified optional packs.

### Blobatar (`Alain00/blobatar`, MIT)

Blobatar generates deterministic geometric faces from a string in about 4.4 KB gzipped. It exposes silhouettes, hue, expressions, backgrounds, idle motion and optional gaze tracking. It is a rendering library, not an agent runtime.

**Decision:** implement an original, tiny SVG/Canvas “Agent Face” using the same useful ideas: deterministic seed, a small shape vocabulary, hue, expression, optional blink/gaze, reduced-motion support. Do not place it behind the notch text or controls. It replaces the eyes only when enabled, is 44–64 DIP, and is clipped inside its own stage.

### Rune (`anomalyco/rune`, MIT, pre-release)

Rune is a native GPU Rust UI framework with its own renderer, text, layout and springs. Its strongest idea for Agent Notch is **headless verification**: render to PNG, dump the element tree, drive scripted input. Replacing Electron with a pre-release Rust UI would discard the existing .NET helper, Electron IPC, Playwright browser control and Windows media integration.

**Decision:** no runtime integration in 0.19. Adopt the idea in tests: deterministic screenshots and scripted input for the new file/face surfaces. Re-evaluate a native shell only if the app moves off Electron.

### Astryx (`meta/astryx`, Meta design system)

A design system for people and agents working together. Useful for token discipline, component state clarity and accessible agent-facing UI.

**Decision:** use its principles in the new surfaces: one card system, clear states, visible labels, no icon-only destructive action, consistent focus rings. Do not add a new UI runtime. The existing React/Eleven components remain the base.

### Handy (`cjpais/Handy`, MIT)

Handy is a Tauri desktop app using Whisper/Parakeet through native inference, Silero VAD and model downloads. Its bundled models are large: Whisper Small ~487 MB, Medium ~492 MB, Turbo ~1.6 GB; Parakeet Q8 ~731 MB. It is a separate app with its own shortcut and paste path.

**Decision:** do not bundle Handy or its models. Add an offline provider that uses an optional **Local Speech Pack**:
- Tiny multilingual Whisper model (target ≤ 150 MB) with a pinned SHA-256.
- Native CPU inference via a small helper (whisper.cpp-compatible), loaded only while transcribing and unloaded after an idle timeout.
- Optional GPU path only if the helper reports it.
- If no pack is installed, the current cloud providers remain unchanged.
- The pack is a user choice, not a silent download.

## Phase plan

### Phase 1 — 0.19.0 (this release)

- Uninstall removes provider keys and integration secrets, even when the user keeps notes/history.
- Lyrics fallback no longer re-renders per word. Only current/previous full lines; no repeated slide-in.
- Agent Face: deterministic blob, shapes, hue, expression, settings preview, notch rendering, click reaction, reduced motion.
- Reviewed File Actions: drop/choose image/audio/video; inspect type/size; image resize/convert via Electron `nativeImage`; explicit output path; no model can invoke it.
- PRD, tests and release notes.

### Phase 2 — optional tool packs

- Download manager with pinned versions and SHA-256 for FFmpeg and LibreOffice.
- Media convert/trim and document conversion only when the pack is installed.
- Undo window and “Open output folder”.
- No background conversion; one job at a time; CPU priority below normal.

### Phase 3 — offline speech

- Local model pack download, hash verification, storage under `%LOCALAPPDATA%\agent-notch\models`.
- Provider selector adds “Local (offline)” only when a pack is installed.
- VAD, 30-second segment cap, cancel, unload when idle.
- Benchmark WER/latency on this machine; never claim offline quality until measured.

## Resource and size budgets

| Item | Budget |
|---|---|
| Installer | < 500 MB (hard ceiling 1 GB) |
| Agent Face | < 30 KB code, no extra runtime |
| File Actions | < 50 KB code; image work uses Electron APIs |
| Optional FFmpeg pack | downloaded, not in installer |
| Optional offline model | downloaded, not in installer |
| Idle CPU | < 1% above current baseline |
| Conversion | one job, below-normal priority, cancellable |

## Security rules

- File actions start only from a visible user drop/choose. The assistant cannot call them.
- File paths come from the OS picker or a dropped `File`; no renderer-supplied arbitrary path.
- Conversion never uses a shell string. Use `execFile` with argument arrays.
- Output is written to a user-approved path; never overwrite the input.
- Optional packs use HTTPS, pinned SHA-256 and a size cap; a failed hash deletes the pack.
- Uninstall scrubs keys and integration secrets even when preserving notes/history.

## Acceptance tests

- Unit: key scrub preserves notes/profile but removes `keys`, integration secrets and agent token.
- UI: lyric fallback no longer re-renders on word index; one current line, one previous, no animation restart.
- Unit: blob output is deterministic for a seed; settings validation rejects bad hue/shape.
- File actions: a PNG resizes/converts to a new path; invalid/cancelled input leaves no file; input is unchanged.
- Packaged smoke: notch still opens/closes, Agent Face renders, file card fits without clipping.
- Size: installer and installed folder measured and recorded.
