The core reference is a small, persistent action strip at the notch. There is no desktop Windows toast in this sequence. Reading and workouts are requested extensions: they use a slightly taller pinned card for a real active-time clock, Pause/Resume, Snooze, explicit completion and Cancel. Reaching a timer target changes the hint; it does not automatically claim the activity happened.

## Animation handling

The four uploaded GIFs are copied byte-for-byte into `src/assets/routines`. No external artwork was downloaded and no browser automation was used. A runtime SVG white-key filter removes the white rectangle while the browser's native GIF decoder retains animation timing and infinite looping. Near-white pixels inside the artwork also blend into the notch; the original files remain untouched. No single-frame replacement or AI redraw is used.
