# Agent Notch 0.21.0 — video and audio in File actions

File Actions now handles **images, video and audio**.

## What works

- Inspect: MP4/MOV/MKV/WebM/AVI and MP3/WAV/M4A/AAC/FLAC/OGG/Opus. The page shows duration and, for video, resolution.
- Trim/convert: when FFmpeg is installed, writes a new MP4 (video) or MP3 (audio) with optional start/end seconds.
- FFmpeg is invoked with argument arrays, never a shell. The source is never overwritten.
- If FFmpeg is missing, the page explains the requirement. The app does **not** bundle or redistribute FFmpeg, so the installer stays under 1 GB and no GPL binary is added.

## Verified

- `npm test`: 295 tests, 295 passed (including media argument tests and image transforms).
- Packaged 0.21.0 test: inspected the user's 1920×1080, 18.08s MP4, then produced a valid **2.000s** MP4 clip (`ffprobe`).
- The pure argument builder rejects in-place output and inverted ranges.

## Limits

- Document conversion and Whisper/Parakeet model packs remain separate.
- FFmpeg must be on PATH or set through `AGENT_NOTCH_FFMPEG`.
- Groq remains the default assistant/transcription provider; Local (Windows, offline) remains the explicit no-key alternative.
