# Agent Notch 0.20.2 — image rotate and flip

- File actions now supports 90°/180°/270° rotation and horizontal flip before conversion or resize.
- The pixel transform is isolated in [src/image-transform.cjs](src/image-transform.cjs) and unit-tested for complete-pixel movement, dimensions and invalid input.
- Packaged test: a 200×100 PNG rotated 90° produced a valid 100×200 PNG. The pure transform tests also pass.
- Groq remains the default assistant/transcription provider; Local (Windows, offline) remains the explicit alternative.
- The installer stays under 1 GB.
- `npm test`: 293 tests, 293 passed.

Video/audio/document packs and Whisper/Parakeet models remain separate, unimplemented slices.
