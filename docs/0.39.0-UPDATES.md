# Agent Notch 0.39.0

Text chat, agentic tasks, voice answers and voice recognition now have separate provider selections. Tasks and voice answers also accept independent model overrides. Existing selections remain valid until changed. Grok (xAI) is included alongside Groq, Gemini, OpenAI, Anthropic, OpenRouter, DeepSeek and Sarvam; recognition choices are limited to providers that actually support speech and the existing local engines. Provider keys remain encrypted and scoped to their own provider.

Voice questions use the voice provider. Action requests go through the task coordinator and its selected planner, then return the verified result to the selected speaking engine. Selecting a text-only model does not pretend that it supplies speech. Sarvam Bulbul v3 has 37 named voices, Groq Orpheus has six, Gemini Live has five selectable presets, and installed Windows voices remain available in Settings. A visible spoken-replies control makes silent answers explicit. Fresh installations enable spoken voice answers; typed replies still have their separate read-aloud preference.

The user's Sarvam key passed live chat, Bulbul WAV generation and Saaras recognition checks using a short generated test sentence. No microphone recording or private video audio was uploaded for these checks. OpenAI, Gemini and xAI connections were not tested live because no corresponding key was available; authenticated request construction and role separation are covered by tests.

Settings opens its themed window promptly, retains a loading cover while the complete controls initialize, and reveals them through a readiness event. Windows startup status is cached instead of querying Windows for every settings read. Installing Windows voice options is deferred in the settings window until the voice section is opened. Newly revealed Astryx fields render synchronously so sections do not briefly lose their controls. A development measurement recorded a 162 ms window appearance and 3.47 s to complete initialization; timings depend on the machine.

The media timeline and volume follow the selected accent. Volume is compact in the regular player with a smaller thumb. Lyric identity no longer depends on transient Windows session wrappers. Media surfaces retain their React instance, and each newly displayed lyric animates once instead of repeatedly fading on refresh.

Hidden Tools no longer changes window geometry during startup. Home resets to its compact automatic height. The default mouse-leave delay is 300 ms, while pinning and active voice capture retain the existing hold behavior. Custom panel dimensions still apply when explicitly selected.

Primary references: [Sarvam voices and model compatibility](https://docs.sarvam.ai/api-reference/text-to-speech/convert), [Sarvam voice categories](https://docs.sarvam.ai/api/integration/build-voice-agent-with-vapi), [Gemini Live voice configuration](https://firebase.google.com/docs/ai-logic/live-api/configuration), [xAI API endpoints](https://docs.x.ai/developers/rest-api-reference/inference), [xAI model identifiers](https://docs.x.ai/developers/rest-api-reference/inference/models).

Validation: 337 unit tests passed, two GUI-dependent tests were skipped, all 30 packaged interface checks passed, and the three live Sarvam checks passed. In the final packaged run, the Settings window appeared in 133 ms and its controls completed initialization in 3353 ms. The 300 ms close-delay check includes intermediate collapse and final hiding. Physical microphone capture was not exercised.
