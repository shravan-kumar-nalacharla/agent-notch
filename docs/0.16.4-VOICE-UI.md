## UI source and scope

Official repository: https://github.com/elevenlabs/ui/tree/3a28ebab197f8cfa599934f52db12ad1396e54f4 . The MIT orb fragment shader is adapted into a local WebGL2 canvas; the full license is shipped. Generated local noise replaces the external texture. Conversation, message/response, voice-button, microphone/voice selectors, level-bar and shimmer patterns are adapted to this app's DOM and native events. This is a source adaptation, not a wholesale React/Next.js migration or an ElevenLabs audio-provider integration. Existing Sarvam/Groq/Gemini provider choices remain in place. No extra microphone stream is opened for the visualization or selector.

The voice view has a larger heading, bold status, actual native input level and actual cloud-playback output level, independent transcript scrolling, copy/replay controls, short book context and an expandable audio-options row. It uses the existing rich panel height, with the same outer motion algorithm. Shared typography raises chat text/inputs to 14px and strengthens headings, settings and tool labels. The full stored context is still editable in Settings.

Manual voice-view opening stays open while idle. An answer keeps the view through recognition, generation, synthesis and actual playback completion. Playback/processing ownership prevents mouse-leave auto-collapse; completion releases it to the original grace timer and pop-out. Stop, mute and explicit navigation retain their cancellation behavior. The four files responsible for outer motion/geometry (`surface-motion.js`, `island-motion.js`, `compact.css`, `geometry.cjs`) are byte-for-byte unchanged from 0.16.3.
