# Agent Notch 0.24.0 — actual Blobatar, drop-on-notch, Nashi copy

## Blobatar copied and active

- Full Blobatar source is vendored at `vendor/blobatar` (MIT, upstream
  `44bdffda5c956563eed11dacfc4bb982e5f333f7`).
- The notch bundle is built from `blobatar/packages/blobatar/src` into
  `src/vendor/blobatar.js`; the old custom shape/eye generator was removed.
- Settings exposes Blobatar's ten silhouettes, fourteen expressions, hue and a
  custom seed. The preview and the notch use the same renderer.

## Drop directly on the notch

- Dragging any supported file over the notch shows a drop overlay.
- Dropping opens **File actions** with the file inspected.
- Visible entry points were added: paperclip in the header and **Files** on Home.
- Verified in packaged 0.24.0 with a 256×256 PNG: the window expands, the File
  actions page opens and the file card is populated.
- The forced-open path clears a reminder HUD so a drop is not swallowed.

## Nashi copied

- Full Nashi working tree is vendored at `vendor/nashi-app` (MIT, upstream
  `a3ae8dbf5498bcc8c17ca5b6eb3a5276cc756ef5`), including its Swift, WPF,
  Windows and resources source.
- Nashi is a native Swift/WPF app, so Agent Notch uses its catalog and
  interaction model rather than loading the native binary.
- Current ported surface: drop, inspect, image convert/crop/rotate/flip, media
  probe/trim/convert (installed FFmpeg), document → PDF (installed LibreOffice).

## Not yet ported

The remaining Nashi catalog entries — PDF organizer/merge/split, archives,
subtitles, QR, metadata, framing/collage, web download, annotation/redaction
and the full media tool set — are not yet in Agent Notch. This is intentionally
tracked as remaining work, not claimed complete.

## Verification

- `npm test`: 297 tests, 297 passed.
- Packaged 0.24.0 Blobatar SVG is rendered from the vendored bundle; the File
  actions button opens and a dropped/inspected PNG appears in the page.
- Installer remains under 1 GB.
