# Agent Notch 0.40.0

Start listening now remains enabled across voice turns. Capture pauses while the provider answers and spoken playback runs, then starts again 250 ms after both playback completion and native microphone release. This prevents recording the assistant's own reply. Stop, Escape, mute, closing the window, switching to push-to-talk, or a provider error ends the loop. Quiet captures retry without an error flash. Gemini Live keeps its existing server-managed continuous session. The upgrade does not start recording automatically.

The voice picker previously allocated a WebGL context for every voice, exhausting contexts and hiding the main ElevenLabs canvas. Picker rows now use microphone icons. The main shader remains mounted during voice selection, restores itself after context loss, and releases its context on unmount. Its plain sphere background is removed. Spoken reply status, Replay and Copy occupy separate grid columns.

Verification: deterministic unit tests cover playback/release ordering, silence, cancellation, stale events, concurrent starts, provider errors and Gemini Live. A backend test holds native release acknowledgment and verifies that completion cannot fire early. The isolated Electron interface check selects multiple voices from the 37-voice catalog, checks context restoration, footer bounds, repeated listening turns, Stop, Escape and mute. Capture and provider responses in this interface check are simulated; physical microphone capture and acoustic echo behavior still need a hardware check.
