# Reminder interaction fix — 0.15.1

The supplied 25.38-second recording shows the water reminder switching to the main home panel when the pointer approaches Refilled or Snooze. The mouse-enter and native-hover handlers could start the normal opening animation while the reminder owned the island. Earlier reminder tests used DOM clicks with hover disabled, so they did not exercise this failure.

The opening controller now checks reminder ownership when an open actually executes, including an already queued hover timer. Main-process activation and expansion requests also preserve the reminder. A pin preference takes effect after the last card ends. Refill retains the water card and does not log a drink; Drink logs a serving; Snooze retains the scheduled occurrence. Existing active main views still defer newly arriving reminders to the pending badge. Duplicate reminder-visibility IPC is suppressed while timer text continues updating.

The new isolated Electron check enables the production hover handlers and sends real renderer mouse-move/down/up events, with a controlled screen-cursor fixture for native hit testing. It reproduces the original refill-hover failure before the fix. Afterward it verifies held button presses, refill/drink/snooze results, queued Next, a running reading timer, opening attempts during a reminder, and recovery of normal hover. The existing reminder check verifies that enabling pin cannot replace a displayed card and that the pinned view returns afterward. This is not a claim of physical mouse testing on another Windows machine.

All 242 unit/regression tests pass. The packaged app passes six pointer scenarios, eleven reminder scenarios with zero Windows toasts, six window/media scenarios, thirteen microphone/privacy scenarios and the existing mouse-wheel scroll regression. All 130 runtime source/assets match the tested ASAR. Installer verification is recorded in the release evidence after completion. The original video and desktop contact sheets are excluded from deliverable QA archives. No native helper or dependency change is needed for this patch. Windows 10 and physical mouse operation on another machine remain unverified.

Deployment completed with installer exit 0. Installed Apps reports 0.15.1, and all nine installed ASAR/native/Chromium hashes match the tested payload. The running copy and Start menu shortcut had pointed at a separate older installation under Local/Programs while Windows registered F:/AgentNotch. That process exited gracefully; the tested F:/AgentNotch copy is now running, and Desktop/Start menu shortcuts point to it. Provider blobs, note, microphone, voice and language preferences were preserved. The private backup is restricted to the current user and SYSTEM and excluded from deliverable archives.
