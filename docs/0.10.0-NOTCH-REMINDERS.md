# Agent Notch 0.10.0 — notch reminders

This release replaces the 0.9.0 Windows-first reminder presentation with **notch pop-ups by default**, following the user's uploaded video. The durable main-process scheduler and tracking database are retained. Windows notifications remain an enabled optional delivery preference; they are sent only if the user selects Windows banners. The default notch path sends **zero Windows toasts** and has no layered Windows toast sound.

## Daily flow

- Water: a compact bottle/droplet card offers Refilled or Drank and Snooze. Refilled restores bottle capacity without adding to daily intake. Drank logs the configured default serving once. Water has no per-occurrence Cancel; busy mode, global off, quiet hours and schedule/category controls still apply. Meeting the daily goal suppresses further prompts unless Continue after goal is enabled.
- Reading: a reminder stays pinned, with an editable session duration. Start runs a main-process active-time clock. Pause/Resume and Snooze preserve that clock. Session completed can log explicitly entered pages and closes the reminder; it does not finish the entire book automatically. Cancel stops the session and closes only that occurrence.
- Workouts: a pinned clock, Pause/Resume, Snooze, Workout completed and Cancel. The card remains after the planned duration until the user acts. Completion never invents exercise/set logs. Open plan shows existing detailed exercise logging.
- Plans: editable Treadmill walk, Dumbbell basics and Walk + dumbbells starters. They create real routines with exercises and durations; no schedule or activity starts automatically. Users choose their own intensity/loads and can edit all details.
- Queues: multiple reminders share one surface with Next. Routine reminders take priority over transient status notices. Routine cards remain until acted on; ordinary status notices expire after eight seconds.

Snooze pauses an active reading/workout clock, hides the occurrence and restores it at its due time with Resume. Later recurring water intervals do not pile up while the same item is pinned or snoozed. Timers survive panel closure. App shutdown/lock/sleep restores paused checkpoints according to existing session rules. Pending notch occurrences restore after restart; showing the card is acknowledged by the actual main renderer before recording delivery.

## Settings and delivery

Settings → Reminders & routines exposes Enable reminders globally, Busy mode, Reminder style and Allow Windows notifications. **Use the existing Save changes button**; these fields participate in that save and preserve drafts during background updates. The same controls also exist in reminder details. The small busy button on a pop-up immediately hides all reminder pop-ups while retaining pending activity; turn Busy mode off in Settings to restore them.

Notch delivery does not require Windows banner permission. Windows mode respects the app's Windows toggle and OS policy. Both modes respect quiet hours, lock/suspend, focus/presentation restrictions and category preferences. User-visible Windows DND remains unknown where no authoritative API exists; the app does not bypass Windows policies. Existing schedule enable/disable choices are preserved. Enable and save a Water schedule for regular interval prompts; the test button does not enable it.

The notch window uses `showInactive`, retains its center anchor and does not request keyboard focus when a reminder arrives. Active voice capture temporarily takes visual priority. A full-screen/presentation veto and global off/busy hide the surface. Details still require an explicit click. No huge home panel opens automatically for a reminder.

## Data and migration

`productivity.sqlite` schema1 is retained. New notification preferences merge with existing saved values; missing delivery defaults to notch, Windows allowed defaults true and busy defaults false. No existing global/category opt-out is overwritten. Original settings/library migration backups remain. Occurrence JSON stores the notch surface, linked activity session and planned minutes; normal action receipts, tokens and de-duplication remain in the shared engine.

Bottle capacity/refill uses a stable drink ID rather than a SQLite row number, so standalone backup/restore can rebuild rowids without changing the remaining volume. Refill does not count as water consumed. A bottle must fit one default serving; invalid combinations fail without partially saving the plan. Existing exports and uninstall data retention still apply. Back up before upgrading; do not delete the app's profile to install this version.

## Install

Run `release/0.10.0/Agent Notch Setup 0.10.0.exe` to upgrade the older tray app. The installer is unsigned and retains the normal per-user NSIS uninstall. Default uninstall keeps personal data; removal of app-owned data remains a separately confirmed choice. Ordinary tray process exit stops reminders; startup follows the existing saved Windows login choice.

## Validation

See [the video analysis](0.10.0-VIDEO-ANALYSIS.md) and [Windows QA](0.10.0-WINDOWS-QA.md). Source tests: 148 passed. Source native-app checks include eleven notch flows with zero Windows toasts,60 desktop, 15 Settings save/scroll, 11 Gemini UI, four speech-behavior and 12 productivity checks. The real 60-second hidden-window test displays a notch card and receives renderer delivery acknowledgement. Packaged verification is recorded in `artifacts/0.10.0/release-verification.txt` after build.

Not verified: physical mixed-DPI/dual-monitor setups, reboot/login, interactive 0.10.0 installation/uninstall, physical toast buttons in the optional Windows mode, live Spotify/Gemini/YouTube accounts and microphone recognition. The user's earlier Windows-banner observation belongs to0.9.0; the 0.10.0 notch tests are separate evidence. GIF sources were supplied by the user; external redistribution rights were not independently established.
