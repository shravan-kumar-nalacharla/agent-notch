# Agent Notch 0.31.0 — File Studio

The notch is compact again. All file editing opens in a separate **Agent Notch — File Studio** BrowserWindow.

- Real image crop and resize, with crop handles and pixel exports.
- Real video preview, filmstrip, trim handles, video crop, mute, speed and snapshot.
- Real PDF.js preview with thumbnails, page rotate/delete/duplicate/reorder, save and PNG export.
- Multi-file queue with remove controls.
- File Studio persists window bounds and uses a restricted preload surface.
- Notch drop, paperclip and Home Files all open Studio.
