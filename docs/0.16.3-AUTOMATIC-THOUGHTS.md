# Automatic thought popups — 0.16.3

This release includes the reading-context improvements from 0.16.2 and implements the user's replacement quote behavior. The previous Home-only, two-per-day/four-hour rules are superseded. The manual Thought button is removed from Home; the thought library remains in Settings. No quote hotkey or Windows toast is added.

## Behavior

Thoughts appear in a separate compact state of the notch, without opening Home or taking keyboard focus. A curved surface adjusts to the localized text. Text rises from 14 px below its final position while opacity changes from 0 to 1; it remains for about five seconds and exits upward. Hover does not prolong it or open the main notch. Reduced-motion and app motion-off preferences show the same text without the animated entrance. Line appearance has an explicit HUD exception so it cannot squash the popup to the idle line's dimensions.

The default is eight scheduled thoughts per local calendar day with a 60-minute average interval, randomized between 45 and 75 minutes. Startup and unlock can request a thought after a brief delay; repeated unlocks are rate-limited. Pending thoughts defer during recording/processing, meetings, focus sessions, fullscreen, settings/main-panel use, active tasks, lock, explicit Hide, Do Not Disturb and configured quiet hours. The target therefore depends on the laptop being awake and available; the app never catches up with a burst after sleep. The daily limit and average interval are editable, and the global enable/automatic/startup switches can turn the feature off.

The persisted next due time and daily count survive app restarts. A nonce acknowledgement from the renderer records a visible thought once; discarded/disabled pending popups cannot consume a slot. There is no hourly copying of the full conversation/dictation history: scheduling uses a small quote-state snapshot. The controller uses only the existing curated catalog, selected language/tone/category, favorites, hidden IDs and existing content opt-ins. Quotes do not call any voice/AI provider.

Windows notification/fullscreen signals suppress when explicitly busy; unknown system notification status falls back to the app's own controls instead of permanently hiding thoughts. Resuming from sleep while the session remains locked does not unblock capture or expose a popup; the actual unlock event restores the saved mode and schedules the thought.
