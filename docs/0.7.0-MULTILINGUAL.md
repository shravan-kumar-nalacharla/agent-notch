# Agent Notch 0.7.0 multilingual preview

The curated five-language quote collection now replaces the old generated English list. Quotes never expand the notch by themselves. App display, quotes, speech recognition, dictation style, assistant text replies and spoken replies have separate preferences. This is an **unsigned engineering preview**, not a fully accepted multilingual production release: live speech accuracy and complete human localization review remain open.

## Implemented

- The supplied JSON is packaged unchanged inside `app.asar`. Its 129 stable IDs hold all 645 texts, provenance, opt-in rules and source notes. Startup/build validation rejects duplicates, missing variants and invalid metadata. The editorial DOCX matches all IDs and all texts.
- Settings has Languages & Voice, Quiet Moments and a searchable offline Thought library. Favorites, mute/undo, export/import, correction-file import/export, snooze, optional role and cross-midnight work/quiet hours persist locally. Switching language retains IDs, favorites and cooldowns. Corrections use `agent-notch-localization-patches-v1` and cannot replace provenance or IDs.
- The scheduler runs only on intentional expansion or an explicit Thought request. It uses two automatic thoughts/day and four-hour spacing by default, blocks the 36 opt-in entries unless enabled, avoids recent IDs/topics and respects voice, timers, fullscreen, lock, user DND, quiet hours and task-switch delay. Unknown Windows notification state suppresses automatic display. There are no proactive quote popups or a second quote timer. Task completions mark a short-lived break opportunity for the next deliberate open.
- Inline quotes clamp to two lines, support favorite/pin/skip/read-more/dismiss, and never request window resizing. Full text appears in the normal Settings library. Native-script fonts and screen-reader language tags are applied. Reduced motion disables quote animation.
- Deepgram Nova-3 adds segmented WAV transcription to the existing native capture route. Auto/code-mixed requests use `language=multi` and separate `en`/`hi`/`te` hints. Display styles never become ASR locale codes. The existing Groq/OpenAI/Gemini adapters remain available; DeepSeek remains a text assistant.
- Explicit cloud-audio consent is required before dictation, chat or meeting uploads. No audio is retained by this feature. Utterances snapshot language/provider settings; recording changes are blocked until finished. Abort, duplicate-final protection, partial segment text and low-confidence drafts are supported. Original transcripts and language/output metadata are preserved in local history, subject to retention.
- Deterministic native-to-Roman transliteration and a small Roman-to-native conversational dictionary produce reviewable drafts. English literals, times, URLs, emails and paths are protected. Script changes require the user to review/edit before one native insertion; cancel never inserts. The existing editable dictionary provides custom spellings. English cleanup receives strict no-translation/no-fact-loss instructions and is skipped for non-English output.
- Voice input device, speech sensitivity, silence-send/manual-stop, local microphone test, read-aloud toggle, installed voice, acoustic language, speed, volume and stop are available. Groq Orpheus is used for English only; Hindi/Telugu use matching installed voices or show an unavailable notice. Roman pronunciation is disclosed as approximate.
- Provider credentials use Electron async OS secure storage, with a main-process cache and legacy ciphertext migration. Saves are serialized. Renderer state never includes keys. Existing capture, hotkey, insertion and geometry services are reused.

## Evidence and open acceptance gates

The validation output and Windows runtime artifacts are under `artifacts/0.7.0`. The final QA files are `multilingual-quote-validation.json`, `multilingual-voice-test-report.md`, `windows-regression-report.md` and `known-localization-issues.md`. Test/build logs are copied alongside them. Exact final test counts, runtime measurements and checksums are recorded there rather than inferred from feature presence.

Quotes work without network or keys. Native-speaker review is required for all five versions of every quote. Common navigation, language controls and library actions are localized; advanced help text and some existing widget labels retain English. A localized notice explicitly identifies that fallback. Do not advertise this build as completely translated or professionally localized.

Transliteration is a draft, not a general translation engine. Unknown Roman words remain unchanged; native-language output can therefore contain Roman text for user correction. Streaming ASR over a WebSocket, a local/offline recognizer, academic Romanization, cloud transliteration, Azure/OpenAI TTS, broad cross-sentence code-switch accuracy and automatic distress/mood inference are not implemented. The selected speech provider can bill the user's account; no live latency/WER claim is made.

Windows `SHQueryUserNotificationState` is only a supplemental interruption veto, not an authoritative Focus Assist/DND or virtual-meeting API. Presentation/fullscreen proxies and internal meeting state are used. External calls and external typing cannot always be identified; use the app's Do not disturb setting. No keyboard-content or screen-content tracking was added. Proactive quote delivery stays disabled and has no enable control.

The supplied references to `quotes.txt` and the old `Agent_Notch_0.4.0_Codex_Production_Fix_Master_Prompt.md` were absent. Original line-level provenance and unspecified prior master-prompt requirements cannot be independently verified. Existing source tests and regression smoke checks were retained.

## Build and recovery

Run `npm ci`, `npm test`, `npm run build:native`, `npm start -- --smoke-test`, then `npm run dist -- --config.directories.output=release/0.7.0`. Node/npm and the .NET 8 SDK are needed for a clean native rebuild; end users need neither. The installer is `release/0.7.0/Agent Notch Setup 0.7.0.exe`, with `SHA256SUMS.txt` next to it. It is unsigned.

Quit the existing tray app before installing. Use Windows Settings to uninstall; the existing uninstaller keeps personal data by default and requires an explicit choice to erase it. This task does not uninstall or overwrite the registered user installation. Install/uninstall/reinstall on a clean Windows profile remains a manual acceptance gate.

On first legacy settings load, `settings.json.pre-multilingual` preserves the previous settings file. Legacy quote favorites are retained separately under `quiet.legacyFavorites` because generated old IDs cannot be truthfully mapped to the curated collection. Other notes/history/widget data are retained. Library writes remain atomic. To roll back, quit Agent Notch, back up the per-user app-data folder, reinstall the previous build and restore the saved settings backup. Keep the library backup if changing quote-history formats. Never choose data deletion during recovery.
