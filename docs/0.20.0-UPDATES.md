# Agent Notch 0.20.0 — optional local Windows speech

0.20.0 adds a real offline dictation option without bundling a model or requiring a key.

## What it is

- Settings → Providers → **Dictation & recorded voice** now includes **Local (Windows, offline)**.
- The main process sends the same captured WAV segments to the native helper's `voice.local` action.
- The helper uses the speech recognizer already installed in Windows (`System.Speech.Recognition`), runs on a worker thread, and returns text/confidence. Audio does not leave the PC.
- No cloud-audio consent and no provider key are required for local mode. Cloud providers remain the default and unchanged.
- Local mode is also accepted for push-to-talk and meeting transcription; meeting notes still need an assistant provider if you want a generated summary.

## Limits

- This is **Windows System.Speech**, not Whisper/Parakeet. Quality and language support depend on the Windows speech pack. The objective's Handy-style model packs remain optional downloads because the smallest useful Whisper model is far larger than the current installer headroom.
- The local path recognizes one segment at a time. Long dictation is segmented by the existing native VAD.

## Verification

- Native helper rebuilt with .NET 8; `voice.local` is in the allowed action list and compiled.
- `voiceStatus` unit test confirms local mode is ready with `cloudAudioConsent:false` and no key.
- Packaged 0.20.0 test: saved `speech: 'local'`, left `cloudAudioConsent:false`, sent a WAV through `window.island.transcribe`, and received `"Eloise announce this is a local speech test"` from the installed Windows recognizer. No cloud provider was contacted.
- The packaged installer is verified by `scripts/verify-release.cjs`; update and data checks use the 0.19.0 path.
- A real microphone quality check still requires the user's voice and installed Windows speech language.

## Not claimed

- Whisper/Parakeet models are not bundled.
- No cloud audio is sent in local mode, but Windows itself may use installed language components according to its own policy.
