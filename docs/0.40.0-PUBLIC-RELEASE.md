# Public update rollout — 0.40.0

Published on 2026-11-13: https://github.com/shravan-kumar-nalacharla/agent-notch-releases/releases/tag/v0.40.0

The public channel previously remained on 0.34.3 because development source pushes did not publish installer assets. The tested 0.40.0 application is now packaged as an NSIS installer and published as the latest stable release.

The workflow now derives the version correctly for release-branch pushes, waits for the packaged checks, uploads to a draft before exposing an update, verifies all expected assets, and checks the anonymous public feed after publication.
