# Agent Notch 0.36.0

The form controls now come from the actual Astryx React package and neutral theme, rather than a visual imitation. Native state and form handlers remain connected to the Astryx inputs, switches, calendar/time popovers, selectors and buttons.

All tools share looping previous/next navigation. Enabled plugins register their own tool interface. Installation is available without an application license-status gate; explicit installation and activation still apply.

The island retracts visibly toward the top, slides between sections and morphs between panel sizes. Focus/Stopwatch controls keep stable positions. Appearance includes custom width and height, accent color and fonts. Settings stay hidden until the complete settings UI is ready. Voice controls are compact, the duplicate microphone action is hidden, pin state has clear opacity, and Blobatar is removed in favor of the default mouse-following eyes.

Clipboard history uses square text/image previews, keeps bounded images in memory, and supports the asynchronous Electron 44 clipboard API. Region OCR uses Windows.Media.Ocr without PowerToys: drag an area, release to extract and copy, and retain the last text in the tool. Hydration offers five- and ten-minute schedules, daily goal progress and visible quiet-hour information.

Validation: complete Node test suite, UI/TypeScript build, rebuilt native engine, and Electron smoke checks for Astryx controls, settings, sizing, hydration, actual clipboard polling, plugin tool registration, native region OCR and closing animation. Paid provider requests, physical microphone/camera capture and a live media download are not part of these checks.
