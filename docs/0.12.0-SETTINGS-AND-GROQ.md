# 0.12.0 — Groq defaults, saved keys and clearer Settings

Groq is the default assistant and transcription provider, using the existing Groq models, with Standard recorded voice chat. Gemini Live remains available as an explicit choice. An upgrade performs this requested default reset once, retaining all encrypted provider keys, language preferences, hotkey preferences, reply settings and other personal data. The original valid settings file is backed up as `settings.json.pre-groq-defaults` before that migration is persisted. Later explicit provider/Gemini selections survive future launches.

## Saved keys

Previously the shared API-key input intentionally became blank after saving. The key was still encrypted in the settings file, but the blank field looked like data loss. Each provider now has an independent password input: Groq, Gemini, OpenAI, DeepSeek and Deepgram. Saved values remain in their fields after Save and are restored when Settings reopens. Each field has its own Show/Hide and Remove control; chat-capable providers also have a Test button. Emptying a field preserves the stored key. Remove stages an explicit deletion for the next Save.

All five changes can be committed together. Validation happens before updating the active state or key cache; invalid batches leave every stored key intact. A failed disk commit rolls the in-memory settings back. Editing during an asynchronous save/key refresh preserves the newer input. Keys stay encrypted on disk with Windows secure storage. A narrow IPC endpoint returns saved plaintext only to the trusted Settings window; normal island/public state, routine windows and exports do not receive these values. Show/Hide deliberately reveals only the chosen field.

## Settings

The sidebar displays one section at a time instead of scrolling through overlapping groups. AI & API keys, Voice & typing, Language, Appearance, Reminders, Integrations, History, Quiet Moments, Thoughts, Diagnostics and About have dedicated views. Model overrides and voice tuning are under Advanced. The Voice page separates dictation, conversation and spoken replies, with Gemini setup shown only when Gemini Live is chosen. Existing settings IDs, save validation, cloud-audio consent and global hotkey activation still use their shared save path.

Every Settings on/off input is styled as a switch and exposes the switch role. Labels remain clickable, Space toggles a focused control, and keyboard focus is visible. There is one content scroller and one fixed Save area, including at 640 × 580. The normal public provider selector does not retrieve saved keys.

## Dictation gradient

The rotating color layer previously sized itself as a very wide, shallow ellipse. Rotation could expose black wedges at the sides of the small dictation HUD. It now uses a centered square/circle large enough to cover the whole surface at every angle. Listening and processing also have a full-surface colored background, with readable light text. The original compact HUD size, always-on-top behavior and voice hotkey are retained.
