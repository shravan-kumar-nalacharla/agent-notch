# Agent Notch 0.11.0 — Windows tasks and voice latency

Agent Notch previously sent unknown commands to ordinary chat without desktop tools. Its single-app parser treated “open brave and open youtube” as one Start menu application name. This release adds a real Windows task executor to typed chat, transcribed voice commands and Gemini Live.

## Behavior

- “Open Brave and open YouTube” resolves directly to Brave plus the YouTube URL. Chrome, Edge and Firefox also use their installed executable with separate arguments, never a shell command. Known website aliases include ChatGPT, YouTube, Google, Gmail, Spotify and GitHub. Polite simple requests such as “Could you open Chrome please?” take the same local path, without a planner API call.
- Other requests go to the configured assistant model with a strict JSON step protocol. It can inspect visible accessible controls, list/focus open windows, launch apps, navigate websites, click, draft text, use a fixed keyboard shortcut list, scroll and wait for loading. It keeps the original goal and action results across up to 24 steps/6 minutes and reads Windows again after each action.
- Progress, task steps and Stop appear in the notch. Message submission, Enter/Save, destructive controls and other non-navigation buttons show a concrete review before execution. Review includes the current visible draft. Stop, Cancel, locking Windows, quitting or stopping the owning voice session prevents further steps. Already completed actions are retained.
- Native window discovery avoids querying UI Automation providers in unrelated apps. Focus uses the requested window's accessibility provider, restores a minimized window when needed, and stops promptly if Windows refuses activation. Native targets are issued by inspection, with a 90-second expiry and single-use snapshot. The native broker checks the foreground application, runtime identity, process, label, bounds and editable field values before acting. An edited field invalidates the old inspection; it cannot silently submit a changed draft. Targets cannot be arbitrary model coordinates. Password fields and their children are omitted; terminal/credential apps are excluded. No arbitrary PowerShell, shell scripts, browser code or executable URLs are exposed.
- Normal conversation does not inspect the desktop. For a Windows task, visible control labels and editable field contents from the inspected window go to the selected assistant provider. Agent observations use UI Automation text, not full desktop screenshots. Existing read-only screen guidance remains available separately.

## Voice responsiveness

Gemini Live exposes `execute_windows_task` as an explicit non-blocking tool, with `WHEN_IDLE` result scheduling. Tasks begin when the tool call arrives; they do not wait for speech playback to end. The model can keep speaking while the executor works, but must wait for the result before claiming completion. `stop_windows_task` cancels the active task. Duplicate tool IDs do not execute twice.

Simple launch requests reach the local command path from that tool, avoiding a second model/planning round trip. The ordinary recorded voice-chat silence threshold is reduced from 1.3 seconds to 0.9 seconds. Dictation editing and its review/consent rules are retained. No action is executed from unstable partial speech: a later “don't open it” must not lose a race to a guessed prefix.

The planner asks providers for JSON output. The old Nūs `thinkingBudget: 0` override was deliberately not copied: its behavior is model-specific and would risk another HTTP400 with newer Gemini models.

## Nūs archive analysis and reuse

The user supplied `nus-desktop-main.zip`, identifying itself as `nus-desktop` 0.2.7, repository `https://github.com/potlakai/nus-desktop`, MIT, copyright 2026 Pranav Desu. Its useful paths are:

- `renderer/app.js`: utterance-end detection at about 900ms of silence, pre-roll, streamed reply display and interruption.
- `companion/src/llm.js`: small structured responses for pointing, JSON response mode and provider streaming.
- `companion/src/guide/session.js`: cancellation generations, observation after each step, target reconciliation and bounded sessions.
- `companion/src/guide/walkthroughs.js`: user-kept walkthroughs resolved by fresh control names; misses return to the live model. This is a useful future optimization, not an unrestricted replay macro.
- `companion/src/guide/voice.js`: transcript cleanup and small utterance classification, adapted in `src/voice-intents.cjs`. Agent Notch preserves meaningful bracketed/parenthesized content and removes only known recognition-noise tags. MIT attribution and the complete license are bundled in `src/assets/NUS-LICENSE.txt` and `THIRD-PARTY-NOTICES.md`.

The uploaded code's Companion guides the user to controls; the examined archive does not contain the described general “open Chrome” voice executor. Its `src/assistant.js` handles semester tasks/events/email drafts with confirmation. Agent Notch therefore retains its own native action broker. No Nūs code was executed, its dependencies were not installed, and its telemetry/auth/billing/CLI integrations and binaries were not copied into the app.

## Verification and limits

Final packaged verification (2026-11-03): 166 unit/integration tests passed. Packaged checks: Windows tasks 9; settings 15; notch reminders 11 (zero Windows toasts); Gemini UI 11; speech 4. All packaged stderr logs empty. 97 src files and 7 native resources match the package. No live cloud requests or physical microphone latency test. Installer unsigned.

The real Windows acceptance fixture uses a separate WinForms app: inspect controls, omit its password field/value, type hi, wait for review, click Send after confirmation and observe “Sent: hi”. It also exercises actual Stop/Cancel, snapshot replay rejection and refusing a draft edited after inspection. The acceptance planner is deterministic; no real message is sent and no live model/account call is made.

Unit/integration tests cover the browser compound command, direct polite launches, safe executable/URL handling, multi-step observations, cancellation, reviews, invalid model steps/targets, bounded failures, JSON requests and simultaneous Live audio/tool dispatch. Existing Settings, notch reminder and Gemini UI smoke checks run with temporary profiles.

This adds an executor, not a promise that every Windows app or every complex task is supported. Canvas-only/custom controls, administrator windows, password/UAC/sign-in flows and unsupported applications may require manual help. Model quality, recognition and network latency still depend on the configured provider. Physical microphone-to-Chrome startup latency, live ChatGPT sending and live Gemini execution were not measured. No account keys were read from the real user profile. The installer is unsigned and must be installed to update the current app.
