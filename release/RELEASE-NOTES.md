# Agent Notch 0.20.2

- File actions now supports **90°/180°/270° rotation** and **horizontal flip** before conversion/resize.
- Edits run locally on the decoded image; the source file is never overwritten.
- Groq remains the default assistant/transcription provider. Local (Windows, offline) remains the no-key alternative.
- The 0.20.1 square crop and all prior fixes remain.

This is an image-editing slice. Video/audio/document packs and Whisper/Parakeet models are still separate optional work.

Installer is unsigned; verify the checksums. Stable alias: `Agent-Notch-Setup.exe`.
